# 📘 EduPattern: Predicting Student Performance Through Behaviour Analysis

## 📌 Overview
This project explores the relationship between student habits and their academic performance. It aims to analyze how different behavioral patterns—such as study hours, sleep duration,diet quality, parents education,extracurricular activities, and internet quality usage—affect final scores. The project also includes a regression model to predict marks based on user input.

---

## ✅ Steps Performed
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA) with Visualizations
- Feature Engineering (e.g., attendance rate, social media time group,sleep hour,diet quality...)
- Regression Modeling using Random Forest
- Streamlit-based User Input Interface for Real-time Predictions

---

## 📊 Features Used
- `study_time`
- `sleep_time`
- `social_media_time and ott`
- `attendance`
- `part time job`
- `diet quality`
- `internet quality`
- `weekly exercise days`
- `extra curricular activities`
- `parents education `

>  Note: All features were used except `exam_score` to avoid prediction bias and maintain generalization.

---

## 🎯 Project Outcome
- Identified key behavior patterns that correlate strongly with academic marks.
- Built a regression model (R² ≈ high) capable of accurately predicting scores.
- Created a Streamlit app where users can enter habits to get predicted marks.
